# One-page editor guide

Log in at `yoursite.com.au/wp-admin` with **your own account** (two-step login switched on). Before publishing anything, check it on your phone.

| Task | Where | Role | If it goes wrong |
|---|---|---|---|
| **Change a fee** | Appearance › Editor › Patterns › **Fee – Standard session** › edit the amount › Save. It updates on Home, Fees and every service page. | Editor | Open the pattern › Revisions › restore the previous version |
| **Pause or reopen intake** | Patterns › **Booking action** › select everything inside › delete › insert the ready-made version (Patterns › *Intake status versions*: Taking new clients / Enquiries only / Waitlist / Paused) › Save. Every page updates. | Editor | Revisions, or insert the previous version again |
| **Change hours, phone, email** | Patterns › **Contact details** › edit › Save | Editor | Revisions |
| **Swap a photo** | Open the page › click the image › Replace › choose or upload › **write the image description** (Alt text) › Update | Editor | Page › Revisions |
| **Edit text on a page** | Pages › choose the page › edit › Update. Locked sections (the practitioner intro) let you change words and images, not layout. | Editor | Page › Revisions |
| **Clinical wording** (title, services, rebates) | Edit the page › **Save as Pending** › practitioner reviews and publishes | Practitioner approves | Revisions |
| **Draft a room** (e.g. Melbourne) | Pages › Add new › choose the **Consulting room page** pattern › fill in › **Save draft** › Preview. A "Melbourne room" draft already exists. | Editor | Drafts are never public |
| **Switch rooms on moving day** | 1) Publish the new room page. 2) Patterns › Contact details: new address, hours and timezone. 3) Appearance › Editor › Navigation: add the new room, remove the old. 4) Old room page › set to Private, and add a redirect from its address to *How sessions work*. 5) Update the location and timezone in the booking system. 6) Check on your phone. About 20 minutes. | Administrator | Revisions on each item |
| **Add a clinician** | Pages › Add new › **Practitioner profile page** pattern › Save draft › practitioner approves › Publish › add to the menu. Delete any section you don't need. | Administrator | Unpublish the page (set it to Draft) |
| **Change colours or fonts** | Appearance › Editor › Styles › Colours / Typography. Or pick a whole style: Clarity (default), Eucalypt or Dusk. | Administrator | Styles › Revisions, or ⋮ › Reset |
| **Reorder the menu** | Appearance › Editor › Navigation › drag | Administrator | Revisions |

**Golden rules**
1. Never type a fee into ordinary text. Always use the Fee pattern, or it won't update with the others.
2. Never put client or health information anywhere on the website.
3. If you edit a template in the Site Editor, that edited copy replaces the theme's version. A future theme update won't show on that template until you choose Templates › (template) › ⋮ › **Reset**.
