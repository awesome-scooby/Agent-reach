What this button can and cannot do. A published HTML page runs inside a sandbox that blocks all outbound network requests, and none of REIWA, Landgate, the ABS, the RBA, Cotality or SQM publish a browser-callable (CORS-open) feed anyway. So this button does not silently phone home. It runs the source-reachability probe, reports honestly that every live source is unreachable from the browser, and opens the manual entry panel below. Paste a new figure, press Recalculate, and the entire model — scores, probabilities, scenarios, suburb ranking — recomputes from your values and stamps a new update time. The repo ships tools/refresh_perth_data.py, which fetches the feeds that are machine-readable and prints the values to paste in.

What the record actually supports

Sample-size warning

Perth has produced three clean peak-to-trough episodes in thirty years and one of them (2008) is barely distinguishable from noise. Every "average cycle length" or "typical decline" on this page is a summary of n≈3. It is a description of what happened, not a distribution you can draw a forecast from. Treat any statement of the form "Perth bottoms every X years" as unsupported.

Back-test against Perth's own history

06 / Would it have worked?
Read this before the accuracy numbers. A back-test needs the historical values of every indicator, month by month. For 2014 onward that mostly exists. For 1996–2013 it does not — not in anything this build could reach. So the pre-2014 back-test runs on a reduced indicator set (price momentum, drawdown, cash-rate direction, WA unemployment direction) and the full seven-family model is tested only on the 2014–2019 downturn and the 2020 trough. Precision and recall computed on 3 events are arithmetic, not evidence. They are shown because you asked for them, with that caveat attached to every figure.
